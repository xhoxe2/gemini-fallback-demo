# Gemini Fallback Demo

Наглядное демо фолбека по цепочке моделей Gemini: `gemini-2.5-pro → gemini-2.5-flash → gemini-2.0-flash`.

Запрос идёт по списку сверху вниз. Если модель «выведена из строя» кнопкой или вернула ошибку — происходит фолбек на следующую. В интерфейсе видно дорожку попыток: кто упал, кто ответил и за сколько миллисекунд.

## Локальный запуск

```bash
npm install
GEMINI_API_KEY=ваш_ключ npm start
# открыть http://localhost:3000
```

Ключ берётся на https://aistudio.google.com/apikey

## Деплой на Render (бесплатно, даёт публичную ссылку)

1. Залейте папку в репозиторий GitHub.
2. На https://render.com → **New → Web Service** → подключите репозиторий.
3. Render подхватит `render.yaml`. В разделе **Environment** добавьте переменную `GEMINI_API_KEY`.
4. Deploy. Через пару минут получите ссылку вида `https://gemini-fallback-demo.onrender.com` — её можно отправлять.

> На free-тарифе сервис «засыпает» при простое; первый запрос после паузы открывается ~30 секунд.

## Как показать фолбек

1. Откройте ссылку.
2. Нажмите «Уронить» на `gemini-2.5-pro` (и при желании на `2.5-flash`).
3. Отправьте запрос — увидите, что верхние модели помечены как упавшие, а ответ пришёл от следующей в цепочке.
